# Анализ продаж интернет-магазина (SQL)

Проект на основе синтетического датасета e-commerce: 7 таблиц, 2000+ заказов, данные за 2023–2025 гг.
Анализ выполнен на SQL (SQLite) — с использованием JOIN, CTE, оконных функций, агрегатных вычислений.

## Стек

- **СУБД:** SQLite (запросы адаптированы под синтаксис SQLite)
- **Инструменты:** DB Browser for SQLite, Python (генерация и загрузка данных)
- **SQL-конструкции:** JOIN, подзапросы, CTE, оконные функции (LAG, SUM OVER, NTILE), CASE, агрегатные функции

## Схема базы данных

```
categories (10 строк)     — категории товаров
    │
products (100 строк)      — товары: цена, себестоимость, категория
    │
order_items (4000 строк)  — позиции заказов: товар, количество, цена
    │
orders (2000 строк)        — заказы: клиент, дата, статус
    │
customers (500 строк)     — клиенты: город, дата регистрации
    │
sellers (20 строк)        — продавцы: рейтинг, дата подключения
    │
reviews (800 строк)       — отзывы: оценка, комментарий, дата
```

## Запросы

| Файл | Что считаю | SQL-конструкции |
|---|---|---|
| `02_revenue_by_month.sql` | Выручка по месяцам + накопительный итог | `JOIN`, `GROUP BY`, `SUM() OVER()` |
| `03_top_products.sql` | Топ-10 товаров по выручке | `JOIN` (3 таблицы), `ORDER BY`, `LIMIT` |
| `04_avg_check_by_category.sql` | Средний чек по категориям | `JOIN` (3 таблицы), `AVG`, `COUNT DISTINCT` |
| `05_rfm_segmentation.sql` | RFM-сегментация клиентов | `CTE`, `NTILE() OVER()`, `CASE` |
| `06_conversion_by_status.sql` | Конверсия по статусам заказов | оконный `SUM() OVER()` |
| `07_mom_growth.sql` | Динамика месяц к месяцу (MoM) | `CTE`, `LAG() OVER()`, `NULLIF` |
| `08_seller_margin.sql` | Маржинальность по продавцам | `JOIN` (3 таблицы), расчёт маржи |
| `09_ab_period_comparison.sql` | Сравнение двух полугодий | `CASE`, `GROUP BY`, агрегаты |

## Как запустить

1. Установить Python 3 (если не установлен — [python.org](https://python.org))
2. Открыть терминал в папке проекта и выполнить:
   ```bash
   python load_sqlite.py
   ```
3. Откроется файл `ecommerce.db` — загрузить его в **DB Browser for SQLite** ([sqlitebrowser.org](https://sqlitebrowser.org))
4. Выполнять запросы из папки `sql/` по порядку

## Выводы

- **Выручка:** выручка демонстрирует некоторую сезонность весной: март, апрель, май и подъем в августе, однако прибыль снижается
- **Топ-товары:** концентрация выручки на 10–15% SKU (правило Парето)
- **RFM:** ~70% клиентов — в сегменте Champions/Loyal, но есть доля спящих
- **Маржинальность:** разброс по продавцам незначительный
- **Конверсия:** ~81% заказов доходят до статуса «доставлен», узкое место — cancelled
